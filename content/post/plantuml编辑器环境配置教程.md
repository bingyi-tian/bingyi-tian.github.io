## 安装visual studio code



## 安装java

开启一个管理员权限的cmd，然后安装java：choco install openjdk



## 2. 安装 Graphviz

Graphviz 用于生成图表布局。

访问 Graphviz 官网

下载 Windows 版本

安装时勾选“Add Graphviz to the system PATH”





## 3.安装 Visual Studio Code 插件

打开 VS Code

点击左侧扩展图标（或按 `Ctrl+Shift+X`）

搜索 "PlantUML"

安装以下插件：

**PlantUML**（作者：jebbs） - 主要插件



然后： "Preview Current Diagram"

按 `Ctrl+Shift+P`打开命令面板
